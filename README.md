# Многослойный персептрон для классификации рака молочной железы

## Описание проекта
Данный проект представляет собой реализацию многослойного персептрона (MLP) с нуля на языке Python для задачи бинарной классификации на основе набора данных характеристик ядра клетки.

В проект реализованы прямое и обратное распространение ошибки, градиентный спуск, функция активации ReLU и функция Softmax на выходном слое.

## Структура репозитория
- `split_data.py`: Скрипт для загрузки, предобработки и разделения данных на обучающую и проверочную выборки.
- `train.py`: Скрипт для обучения модели. Реализует архитектуру сети, обратное распространение ошибки, сохраняет веса в `model.npz` и строит графики кривых обучения (`learning_curves.png`).
- `predict.py`: Скрипт для загрузки модели, выполнения прогнозирования и оценки качества с помощью метрик Accuracy и Бинарной кросс-энтропии.
- `data.csv`: Исходный набор данных.
